02 / Using it · copy dist/, and nothing else

Two files, both in dist/. Copy them into your app; do not link to this folder. Launchpad roots every project at its own directory, so a path out of it cannot be fetched at runtime and there is no build step to resolve one. Everything at the root is this documentation site and its source. dist/ is the part that is yours.

FileWhat it is
dist/skew.cssEvery part's material, this site's own rules removed. Wrapped in @layer skew, so your own .card, .row, .box, .key and .wrap keep beating it without a rename and without an !important
dist/skew-kit.jsEvery factory, on window.SkewKit: knob, fader, rangeFader, rotary, drum, key, pkey, swBtn, openPicker, windowise. All five value controls carry .set(), which is what a loaded config pushes through
skew-machine.cssAt the root, and only for plotter parts: DRO, e-stop, jog, annunciator, meter. No Portrait app needs these
Never hand-edit a copy Not dist/ here, not the vendored file in your app. A patch on a generated file disappears at the next build, silently, and you find out when a control stops matching this page. Anything your app needs that the kit does not give goes in a file of your own, beside it.

Why the kit is on window.SkewKit rather than loose: the source is a plain script whose factories are top-level consts. An app running p5 in global mode has its own global key, and two of those collide without throwing. So dist/ wraps the body in an IIFE and publishes the API. The body is byte-identical to the source.

CommandWhat happens
node tools/build-dist.mjsHere. Reports whether dist/ still matches the source; --write rebuilds it. Run it after any change to skew.css or skew-kit.js
node tools/kit-css.mjsIn your app, optional. Reads the class names your own code writes and keeps only those rules, so a small panel does not ship the whole language. Portrait-Typo and Portrait-ribbons both have one
@layer skew, app;One line in your own stylesheet, before anything loads. Optional: layers already order by first appearance, so this only says it on purpose
A panel from a specPast about twenty controls, hand-composing stops paying. Portrait-ribbons/src/skew-panel.js is the working answer: one row per parameter, the factory chosen from the parameter's own shape, .set() registered for the config load
