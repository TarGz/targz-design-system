01 / The contract

A region is a function. tone(x, y) — negative outside, 0…1 inside. Any subject that answers it can be filled by any generator here.

Everything is millimetres. One unit out is one millimetre on paper. Get it wrong and every number below means nothing, and it will still run.

02 / The three layers

LayerWhat it is for
KITWhat is being drawn on. scene, blob, the line families, carve. Shared, so two fills of one idea cannot drift apart
HANDSA look. draw(kind, w, h, seed, opt) — hand, cross, random. §03
HATCHA machine. scanlines, stitch, cut. §03
Three names, not one One namespace would say a hand and a scanline are the same kind of choice.

03 / The fills

Nine of them. The type — a hand, a machine, one of the newer ones — is a line on the tile and nothing structural, because it was never the reason to pick one. What separates them is what carries the tone, and what it costs at the machine.

And the nine at the reference setting — same pen, same pitch, same angle — so they stay comparable. The bay above is where you take one off it.

04 / The API

One tag. Defines KIT, HANDS, HATCH and touches nothing else. No DOM.

KIT what is being drawn on
KIT.scene(w, h)
ball · table · lamp · two tone functions
KIT.blob(w, h, seed)
closed shape with a hole · tone, rings
KIT.parallels(…) · KIT.latitudes(…)
straight lines · curves that follow the form
KIT.carve(runs, tone, tau, dither, minLen)
where tone becomes geometry
HANDS a look
HANDS.fill(kind, w, h, seed, region, opt?)
the three hands on any region — region: { tone, rings? }. How many passes is asked of the tone: a flat region gets two, a toned one four. The wrapping pass is streamlines over the field the tone implies, because latitudes wraps a sphere and a teapot has no axis to give it
HANDS.draw / .drawShape(kind, w, h, seed, opt?)
the same hands on their own built-in subject — the ball, and the blob → { paths, nib }
opt: { nib, spacing, angle } mm, mm, degrees. Pitches are multiples of spacing, pass angles offsets from angle; spacing defaults from the nib. angle does nothing on 'random', and cannot.
HATCH · fills a region in, runs out
HATCH.scanlines(w, h, pitch, angle, margin?)
passes clipped to the sheet, so every endpoint is on the boundary — where you can see the pen turn
HATCH.streamlines(w, h, tone, opt?)
evenly spaced, bending with the tone · tone is the separation, not a threshold
opt: { near, far, bend, angle, nib }
HATCH.squiggle(w, h, tone, opt?)
amplitude-modulated rows · nothing is ever broken, so a region stitches to one stroke
opt: { pitch, amp, wave, angle, nib }
HATCH.spaceFill(w, h, tone, opt?)
a Hilbert curve one level deeper where it is darker
opt: { pitch, depth, levels, nib }
HATCH.labyrinth(w, h, tone, opt?)
one closed curve, grown until the region is full
opt: { near, far, iters, cap, seed, nib }
HATCH · the rest ordering, and getting it out
HATCH.stitch(runs, bridge)
the serpentine · the bridge decides what is legal, and it carries the WHOLE run — reduce straight chords yourself, before chaining
HATCH.cut(reach, inside)
the usual bridge: short enough, and staying inside the region. Publishes its reach, which is what lets stitch bound its search
HATCH.toneField(tone, angle, bend)
the direction field the streamlines use · a base angle bent toward the iso-tone
HATCH.toPoly(run)
path data, two decimals, in millimetres
Everything is millimetres
