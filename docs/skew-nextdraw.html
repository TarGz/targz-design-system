01 / Locked

Boots into this, and drops back to it after two idle minutes — including mid-plot, because a long plot is exactly when you walk away. The plot stays fully readable: bed, meter, percentage, time left. What is gone is not greyed out, it is not in the widget tree at all — the lock is a screen, not an overlay, so unreachability is structural rather than a flag sixty widgets have to remember. The E-STOP still works. Releasing it does not.

02 / Files

Browse and arm. That is all. No upload, rename, move or delete — every one of those is destructive, awkward without a keyboard, and already better on the laptop, because the web UI is running on this same server the whole time. Drop files in over SSH or from the browser and they appear here on the next poll. With nothing armed, the right card shows the last eight plots instead.

03 / Plot

Pick layers as an ordered sequence — the badges say 1 → 2 is a plan, not a set — then OPTIMIZE, then START. The preflight is mandatory and the server enforces it, so rather than hide that, the bed is empty until you press OPTIMIZE and says so. Pressing it is how you get to see the picture, which turns the one unavoidable gate into the reward for passing it. START stays dark with the reason engraved under it.

04 / Run

The app comes here by itself the moment the machine starts moving. The whole drawing sits on the sheet in dim grey, and each stroke lights phosphor green as the pen actually lays it down — the plan is cut into 87 pieces of equal drawn length, so the fill tracks the pen instead of stalling and jumping. Orange is the pen-up travel between strokes; green and amber dots are where the pen lands and leaves. HOLD and RESUME are one key in two positions. STOP asks twice, because it throws the resume point away for good.

05 / Jog

52px keys, and the arrangement is the axis, so it needs no legend. The 3D joystick from the web UI is gone — on a 7″ screen your finger covers the cap, and it was sixteen barrel slices of CSS that Kivy cannot do anyway. Press and hold a pad key instead and it posts the same continuous stick vector, at the same 120ms, released seven different ways. Jogging stays live while a plot is held: pause, change the pen, resume.

06 / Set

A rotary knob is a lovely object and a poor touch target — you cannot twist something your fingertip is sitting on. Every setting is label, minus, value, plus at 44px, with hold-to-repeat, debounced 280ms so a held key does not fire twenty POSTs. Changing any of the four settings that affect the path invalidates the preflight, and the server says so by marking it stale — which is why START goes dark again the moment you touch GAP.

07 / What is deliberately not here

No file management, no rotary knobs, no 3D joystick, no pinch-zoom on the bed — the panel is single-touch. No hover states, because there is no pointer. No transitions: three frames at 30fps reads as a stutter, and a snap reads as more mechanical, not less. The screws, the brushed anodising and the panel sounds are all in the design system and all left out, because each one costs a texture or a thread and none of them is the reason you look at this screen.
